# 校园二手交易网站

这是一个可以直接在浏览器中运行的校园二手交易网站演示版，页面和功能按照毕业设计正文中的系统设计制作。

## 运行方式

双击 `启动网站.bat`，或者在浏览器中直接打开 `index.html`。

也可以在本目录打开命令行，运行：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173`。

## 演示账号

- 普通用户：`student` / `123456`
- 管理员：`admin` / `123456`

## 主要页面

- 首页：分类浏览和最新商品
- 全部商品：分类筛选、关键词搜索和价格排序
- 商品详情：查看价格、成色、地点、联系方式和收藏
- 发布商品：填写商品信息并提交管理员审核
- 我的商品：查看审核状态、编辑商品、标记已售出
- 我的收藏：查看收藏的商品
- 个人中心：查看账号资料和统计信息
- 后台管理：审核、上架和下架商品

## 数据说明

演示数据保存在浏览器本地存储中，不需要安装 PHP 或 MySQL。清除浏览器站点数据后，网站会恢复默认演示数据。
